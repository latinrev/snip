Pulling the numbers yourself

Every chart here comes from the public API.

// Revenue by month for the current quarter
const orbit = new Orbit({ token: process.env.ORBIT_TOKEN });
const report = await orbit.reports.get("revenue", {
  from: "2026-07-01",
  to: "2026-09-30",
  groupBy: "month",
});
console.table(report.rows);
